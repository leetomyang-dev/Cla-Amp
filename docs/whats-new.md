# What's new

What changed in Cla-Amp, newest first, in plain words. To get the newest
version, close Cla-Amp and double-click **Update.bat** in its folder.
**Check for updates** in About (the **i** button) says whether one is out.

## 20 November 2026

- **Check for updates.** A button in About asks Cla-Amp's page on GitHub whether a newer version is out, and lists what is new. It asks only when you press it and downloads nothing.
- **Connectors a folder brings are asked about first.** If a folder you trust has a `.mcp.json` file that starts programs as connectors, Cla-Amp now asks about each one by name before your first message there. Until you say yes they stay off.
- **Newer Claude Code inside.** Cla-Amp now runs Claude Code 2.1.330, the same version as the Claude desktop app. It fixes background agents that were reported as still running after they were stopped.
- **Paths in a reply are links.** Click a file path to show it in its folder, or a folder path to open it. A link never starts a program.
- **Clearer about your data.** The Privacy guide now says what Claude Code itself sends to Anthropic (your chats, usage numbers, error reports), that none of it reaches Cla-Amp's author, and how to turn parts of it off. The start screen says which kind of account Anthropic documents for apps like this.
- **This page.**

## 17 November 2026

- **Two new spectrum looks:** Glow tiles and Live wires.
- **The spectrum keeps working when your speakers change.** Switching headphones or the default sound device no longer leaves it flat.
- **See what a background command did.** Click a background command's row for its command, its result and its output, while it runs and after it ends.
- **Pictures in an agent's window open large,** like pictures in a chat.

## 16 November 2026

- **See what agents are doing.** An agent's window shows its thinking, the tools it used, how long it has run, and works for agents that were resumed.
- **Stop one agent or command.** Each background row has a stop square.
- **A warning before closing** names any agents and background commands still running.
- **Spell check.** Right-click a word in a text box for suggestions.
- **Arrange the window yourself:** move, hide and resize its parts; a browser of its own; one window per music player.
- **Languages:** the window in eleven languages besides English.
- **Notices, mute buttons, limit reminders,** and picking up where you left off.
- **Security and privacy pages,** and public checks on every change.
- **First version (0.1.0).**
